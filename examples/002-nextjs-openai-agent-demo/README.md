# Next.js and OpenAI Agent Demo — Public Replay Artifacts

This directory contains exactly four public virtual artifacts generated by the certified Fixture
replay workflow:

- `migration-up.sql` — a deterministic, review-only forward compatibility template.
- `migration-down.sql` — the paired rollback template and limitations.
- `validation.sql` — deterministic pre/post checks grounded in known schema evidence.
- `rollout-plan.md` — the staged coordination plan, PR review summary, reviewer gates, and human
  approvals.

The golden sanitized fixture reports 24 visible downstream assets, 11 column-confirmed assets, a
risk score of 90, and `BLOCK_DIRECT_RENAME`. Those facts come from the deterministic impact engine,
not the model.

## Evidence and Context

**Evidence Completeness** reports whether dataset search, schema, table lineage, and column lineage
were collected without known truncation or pagination gaps. **Context Coverage** separately reports
how much bounded descriptive, ownership, and tag/glossary context was available for inspected
assets. Context Coverage explains metadata richness but never changes the 24/11/90 impact result.

The source DataHub name is not a separately verified three-part physical Snowflake name. The
execution classification is therefore `NON_EXECUTABLE_TEMPLATE`: these files are review aids, not
approved or executable migration commands.

## Replay Honesty

Replay runs the committed sanitized fixture and deterministic fake provider without DataHub,
OpenAI, network access, or credentials. It demonstrates the same validated browser and artifact
contracts, but it is not a claim that a live service was queried. Live DataHub + OpenAI evidence is
recorded only in `docs/live-verification.md`, which may truthfully remain `NOT RUN`.

Only these four artifacts are public. Snapshot metadata, normalized context, model draft,
validation findings, hashes, tokens, native envelope paths, temporary names, and raw provider or
MCP data are intentionally excluded.
